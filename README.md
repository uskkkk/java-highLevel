# 김영한의 실전 자바 고급 1편 학습

인프런 **김영한의 실전 자바 - 고급 1편 (멀티스레드와 동시성)** 강의를 들으며 정리한 학습 저장소입니다.
강의 내용을 정리하고, 이해가 부족했던 부분은 `[보충]`으로 덧붙여 기록합니다.

## 학습 목표
- 프로세스와 스레드의 차이, 운영체제의 스케줄링 방식 이해
- 자바에서 스레드를 생성하고 제어하는 방법 익히기
- 멀티스레드 환경에서 발생하는 동시성 문제와 해결 방법 학습
- 실무에서 사용하는 동시성 라이브러리(`java.util.concurrent`) 활용
